Questions fréquentes

Tu veux savoir comment ça marche ?

Est-ce que je peux utiliser CVPro sur mon téléphone ? +
Oui. L'interface est conçue pour fonctionner sur les smartphones Android et les ordinateurs.
Est-ce que je dois créer un compte ? +
Dans cette première version, non. Ton brouillon peut être sauvegardé directement dans le navigateur de ton appareil.
Comment fonctionne Premium ? +
Tu choisis Premium, tu effectues le paiement et, une fois la transaction confirmée par le système de paiement connecté, les fonctionnalités Premium sont activées.
Quels moyens de paiement seront disponibles ? +
L'architecture est prévue pour intégrer les solutions disponibles dans ton marché, notamment Orange Money, Moov Money et Wave, selon les API et prestataires accessibles.
