Questions fréquentes

Comment fonctionne CVPro ?

Est-ce vraiment gratuit ? +
Oui. Toutes les fonctionnalités du créateur sont accessibles gratuitement : modèles, photo, couleurs, langues, certifications et export PDF.
Puis-je ajouter ma propre photo ? +
Oui. Utilise le bouton de sélection de photo dans l'éditeur. La photo apparaît immédiatement dans l'aperçu du CV.
Le CV est-il adapté à une feuille A4 ? +
Oui. Le modèle est conçu avec les dimensions A4 et les paramètres d'impression sont configurés pour générer une page propre.
Mes informations sont-elles sauvegardées ? +
Oui. Les informations du CV sont sauvegardées automatiquement dans le stockage local du navigateur sur ton appareil.
